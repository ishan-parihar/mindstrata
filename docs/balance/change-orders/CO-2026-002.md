# Change Order CO-2026-002 — H6 close: secondary relief map (DC-1)

Status: RATIFIED 2026-08-29.
Owner: DESIGN + SIM. Reference: `AGENTS.md` §4, `docs/architecture/AP4-studio/contracts/IC-5-canon.md` v1.0.0.

## Trigger

`i277_needs_calibration_sweep` (12-seed × 19 needs × 2000 ticks) showed
13/19 needs saturating to deficit 1.0 (the cap) across all 12 seeds
before this CO. Mechanism: only 6/19 needs had `relieve()` paths in the
action-kind table at `crates/mindstrata-sim/src/sim/core.rs:636-684`
(`Socialize`→attachment/belonging, `Worship`→meaning/certainty,
`Trade`/`Work`→competence/recognition, `Rest`→sleep). The remaining 13
(Health, Warmth, Safety, Esteem, Autonomy, Novelty, Play, Care, Romance,
Justice, plus the under-relieved primary pair Attachment, Belonging,
Recognition) had no relieve() in the action map; their deficit grew
monotonically under the dominant-need gate.

This is a **pre-existing structural issue** (verified pre-CO-2026-001
with the same saturation pattern) and was logged as **H6 — psychological-
need relief gate** systemic debt in
`docs/architecture/AP4-studio/runbooks/calibration-audit-v2.md` v2.1.0.

## Fix shape

Each of the 5 relief actions (`Socialize`, `Worship`, `Trade`, `Work`,
`Rest`) gains a **secondary relief** to 2 unmet needs at 0.2–0.4×
primary magnitude. The dominant-need gate is **unchanged** — action
selection still routes on the top deficit. Only the relief map is
widened. Magnitudes chosen so a starving agent (Hunger 0.008/tick) does
not see secondary needs (max 0.003/tick) dominate.
