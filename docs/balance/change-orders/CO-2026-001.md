## Old contract (DC-1 v1.0.0 pre-co)

`system_development` routed **all** incoming catalyst pressure to the
**Dark Addiction** quadrant only:

```rust
let q = &agents[idx].development.pathology.dark_addiction;
let stepped = q.step(Metabolism::Addiction, admitted, &params);
agents[idx].development.pathology.dark_addiction = stepped;
```

Mechanism: the 4-quadrant `PathologyField` was defined and
*zero-at-zero identity-preserving* (`QuadrantState::step` at
`crates/mindstrata-development/src/dynamics.rs:93-112`), but only one
slot moved under real pressure. The other three quadrants were inert
**despite** having the proper `Polarity × Metabolism` shape from the
ratified 4-fold dark/golden × addiction/allergy operator.

**Why this was wrong:** The canon-ratified 4-quadrant model from
`docs/balance/pathology-curves.md` says the operator is
`(Polarity, Metabolism)`-indexed, **not** a single dark-addiction
channel. The old contract conflated "the most pathological pathway" with
"the only pathway," violating the 4-fold symmetry the operator ratifies.

## New contract (DC-1 v1.0.0 post-co)

`system_development` now fans out per `CatalystKind`:

| CatalystKind    | Polarity | Metabolism | Slot moved      |
|-----------------|----------|------------|------------------|
| Threat          | Dark     | Addiction  | dark_addiction   |
| Transgression   | Dark     | Allergy    | dark_allergy     |
| Bond            | Golden   | Addiction  | golden_addiction |
| Grief           | Golden   | Allergy    | golden_allergy   |

```rust
let path = &mut agents[idx].development.pathology;
let (polarity, metabolism) = match kind {
    CatalystKind::Threat => (Polarity::Dark, Metabolism::Addiction),
    CatalystKind::Transgression => (Polarity::Dark, Metabolism::Allergy),
    CatalystKind::Bond => (Polarity::Golden, Metabolism::Addiction),
    CatalystKind::Grief => (Polarity::Golden, Metabolism::Allergy),
};
let slot = match (polarity, metabolism) {
    (Polarity::Dark, Metabolism::Addiction) => &mut path.dark_addiction,
    (Polarity::Dark, Metabolism::Allergy) => &mut path.dark_allergy,
    (Polarity::Golden, Metabolism::Addiction) => &mut path.golden_addiction,
    (Polarity::Golden, Metabolism::Allergy) => &mut path.golden_allergy,
};
*slot = slot.step(metabolism, admitted, &params);
```

**Identity law preserved:** `QuadrantState::step` returns the state
unchanged when both `pressure == 0.0` and `intensity == 0.0`
(`dynamics.rs:96`). All empty-window and zero-cohort tests stay green
**at the producer level**; downstream behavioral pins that used the old
single-quadrant pressure routing as a *side effect* are re-anchored
below.

## What invariant is preserved

Per AGENTS  rule 4, re-contracts guard the **real invariant**, not the
**magnitude**. The invariants preserved by this CO are:

1. **Zero-at-zero identity** (the operator's own law): empty-window and
   zero-cohort tests stay green at the producer level.
2. **Liveness** (a dead producer is a bug): 4-quadrant fan-out
   guarantees all 4 slots step under real pressure, so no producer is
   ever silent.
3. **Seed-family sweep `i268` pass rate ≥ 11/12**: 12-seed family
   re-verified green at v1.0.0 (CA-5).
4. **Cross-quadrant pressure conservation**: total pressure
   admitted to the field equals the sum of per-quadrant deltas
   (preserves the IC-3 determinism law on pressure accounting).

## What changed is a re-contract (not a re-pin)

Per AGENTS  rule 4: **re-contract = the old assertion tested something
the new path legitimately invalidates.** The old assertions assumed
single-quadrant routing; the new path is 4-quadrant, so the
*magnitude* changed by mechanism, not by drift. The decision rule:

* If the test guards **liveness** (a producer is alive): unchanged.
* If the test guards **magnitude** (a specific value band): re-pin
  with mechanism documented (this CO).
* If the test guards an **invariant** (zero-at-zero, liveness sweep,
  conservation): unchanged.
