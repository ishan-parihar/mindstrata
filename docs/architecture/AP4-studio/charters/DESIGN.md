# DESIGN — Game Design & Balance

**Mission**: the player's experience is tuned, not accidental — canon values, pacing,
difficulty, economy curves. We own VALUES inside frozen structures; structure itself
belongs to its builder.

Territory: `docs/balance/**`, calibration values via IC-5 change-orders.

## Standing rules
- No constant changes without probe evidence naming measured value + mechanism (AGENTS.md
  §4.2 form). Theory citations required for theory-derived targets.
- Re-contract explicitly when staged development invalidates old assertions.
- Player-facing specs (pacing/difficulty) cite observable playthrough probes.
